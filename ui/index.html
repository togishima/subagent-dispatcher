Predicate effectiveness

Per node: how often traversal reached it, how confident the evaluator was, and what happened downstream of each branch. A predicate whose branches have the same outcome is not routing anything.

Same policy, different evaluator

Who answered the policy graph's semantic predicates. The graph is identical across these rows, so a difference here is a difference in the evaluator, not in the routing policy. Latency is the obvious difference and the least interesting one — an evaluator that answers in 15 ms but under-routes is worse than one that takes 300 ms and does not.

Routing latency

Median and p95 of the evaluator's own reported time, measured only. Local inference and a network call on one scale.

Predicate agreement

How often each evaluator answered yes to the same predicate. Task text is not stored, so this is not a replay of identical inputs — it is the distribution per predicate. A wide spread means the evaluators disagree about what that question means.

Does a better brief buy a cheaper worker?

Delegations grouped by how completely the caller specified them. A complete brief — the plan, the files to change, and a checkable definition of done — should route cheaper and escalate less. If it does not, the routing policy is not reading specification well.
